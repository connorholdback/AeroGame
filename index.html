Install AeroLab 2D as a Native App

Full-screen standalone mode on iOS & Android

iPhone / iPad (Safari):

Tap the Share button at the bottom of Safari and select "Add to Home Screen". With the embedded app manifest & touch icon now active, opening it from your Home Screen launches in 100% full-screen standalone mode without browser bars!

Android (Chrome / Edge):

Android Chrome requires both a manifest.json (now embedded automatically!) and a sw.js Service Worker file in your GitHub repository to unlock true "Install App" instead of "Add Shortcut".

Optional: Drop that 20-line sw.js file into the same GitHub folder next to index.html so Android Chrome enables one-tap offline installation.
